# ماين ستريم | Mainstream — موقع الوكالة

> نصنع الضجة.. وأنت تملك الأضواء · WE CREATE THE HYPE. YOU OWN THE SPOTLIGHT.

موقع وكالة ماين ستريم للتسويق في الرياض. صُمّم على الهوية البصرية الرسمية (Mainstream Brand Guidelines). مبني بـ **Next.js 16 + React 19 + TypeScript**، عربي بالكامل (RTL)، والهدف الأساسي منه: **الزائر يحجز اجتماع عبر واتساب**.

---

## التشغيل في Visual Studio Code

### أول مرة

1. افتح الملف **`mainstream-website.code-workspace`** بالضغط المزدوج (أو من VS Code: File ← Open Workspace from File).
2. لو طلع لك تنبيه "Do you trust the authors"، اختر **Yes**.
3. لو اقترح عليك VS Code إضافات (Extensions)، اضغط **Install All**. هي اختيارية لكنها مفيدة.
4. شغّل المهمة **"1. تثبيت المكتبات"** (`Ctrl+Shift+P` ← `Tasks: Run Task`). تحتاجها مرة وحدة فقط.

### كل مرة

- اضغط **`Ctrl+Shift+B`** وبيشتغل الموقع على: **http://localhost:3000**
- أو من قائمة **Run and Debug** (`Ctrl+Shift+D`) اختر **"تشغيل الموقع + فتح المتصفح"** واضغط ▶ (أو `F5`).
- للإيقاف: اضغط على التيرمنال ثم `Ctrl+C`.

> بدون VS Code: اضغط مرتين على **`تشغيل-الموقع.bat`**.

### المتطلبات

- **Node.js 20 أو أحدث** (مثبّت على هذا الجهاز: v24).
- على جهاز ثاني: نزّله من [nodejs.org](https://nodejs.org) ثم شغّل "1. تثبيت المكتبات".

**كل الأزرار تفتح واتساب برسالة جاهزة** تناسب الزر (حجز اجتماع، سؤال عن خدمة، حجز باقة الكوفيهات، طلب سعر الفريق).

### لمسات تفاعلية

- كل العيون في الموقع **تتابع مؤشر الماوس** (على الكمبيوتر فقط).
- لما تمرّر الماوس على أي كاميرا في جدار المراقبة، المنظار ينتقل لها.
- الأزرار "تنضغط" في ظلها عند الضغط.
- الموقع يحترم إعداد "تقليل الحركة" في الجهاز: يظهر بدون حركات.
- متجاوب بالكامل: جوال، تابلت، كمبيوتر.

## ⚠️ ناقص قبل النشر

1. **رقم الواتساب الحقيقي**: افتح `lib/site.ts` وغيّر `WHATSAPP_NUMBER` (الصيغة: `9665XXXXXXXX` بدون `+`).
2. **حساب الانستقرام**: في نفس الملف، غيّر `INSTAGRAM_HANDLE`.
3. **أعمال العملاء**: لما تجهز، تنضاف في قسم «قائمة المراقبة» (`app/page.tsx` ← دالة `Watchlist`).
4. **الدومين**: عند النشر، ضع متغير البيئة `NEXT_PUBLIC_SITE_URL` برابط موقعك (عشان صورة المشاركة في السوشال).
5. **قاعدة العين على الخلفية الفاتحة**: العين تظهر على ورق فاتح داخل الكاميرات. تعاملنا معها كعنصر بصري مستقل وليس كشعار، فأكّد إذا هذا مناسب لك.

## النشر (لما تكون جاهز)

أسهل طريقة: **[Vercel](https://vercel.com)** (مجاني للمواقع الشخصية):

1. ارفع المشروع على GitHub.
2. من Vercel: Add New ← Project ← اختر المستودع ← Deploy.
3. اربط الدومين حقك من الإعدادات.

أو يدوياً: `npm run build` ثم `npm run start`.
